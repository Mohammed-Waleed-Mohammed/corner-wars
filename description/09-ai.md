# 09 — AI Opponents

Three AI players, each running the same brain, each treating all other players as enemies. Start simple, deepen later.

## Difficulty tiers

**Easy**
- Ramp Workers to ~6.
- Build a Barracks; spam Riflemen.
- Build a Power Plant when in low-power.
- Every 60 s, send the whole army at the **nearest enemy base**.

**Medium**
- Maintain ~10 Workers.
- Build order: Power Plant → Barracks → War Factory.
- Field a **counter-aware mix**: scout the nearest threat's army and lean toward its counter (`05-units.md`).
- Send idle units to contest the **Citadel**.
- Pull Workers to defend when its base is attacked.
- Use Citadel powers when it holds them (Artillery on clumped enemies; Ion Strike on a base).

## Target selection (keeps the FFA dynamic)

Pick the **weakest reachable enemy** (fewest units / lowest base HP), not always the human. This makes the AIs fight each other and prevents a 3-on-1 pile-up on the player.

## Suggested state machine (per AI)

```
EXPAND      -> economy below target: build Workers / Refinery
BUILD_ARMY  -> economy ok, army small: pump units, build tech
ATTACK      -> army strong enough: march on weakest enemy or the Citadel
DEFEND      -> own base under threat: recall army + Workers to defend
```

Drive transitions off three signals: current gold/income, army size vs a threshold, and incoming-threat detection (enemy units near own base). A simple per-tick evaluation of these is enough for a fun first version.

## Notes

- The AI uses the same rules and numbers as the human — no cheating economy in v1. (You can add resource handicaps later for harder difficulties.)
- Keep AI decision-making on a slower cadence than the render loop (e.g. re-evaluate every 0.5–1 s) for performance and more human-like behavior.
